# Global Cyber Security Threats Analysis (2015-2024)

## Project Overview
[cite_start]This project provides a deep-dive analysis into how cyber-attacks have evolved over a 10-year period (2015–2024). [cite: 3] [cite_start]By examining a comprehensive dataset of over **3,000 recorded incidents**, the study identifies who is behind the attacks, the methods used, and which countries are hit the hardest. [cite: 4, 7]

* [cite_start]**Timeline:** 2015 – 2024. [cite: 3]
* [cite_start]**Data Volume:** 3,000+ attack records. [cite: 7]
* [cite_start]**Interactive Element:** Power BI dashboard for exploring threat data. [cite: 9]

## Problem Statement
[cite_start]In the modern digital landscape, cybersecurity data is often massive and unorganized, making manual identification of trends nearly impossible. [cite: 16, 17]
* [cite_start]**Invisible Trends:** It was unclear if global attacks were increasing or decreasing over the decade. [cite: 19]
* [cite_start]**Target Blindness:** There was no easy way to see which specific countries or industries were facing the most threats. [cite: 20]
* [cite_start]**Defense Gaps:** It was difficult to measure how effectively different industries were resolving incidents. [cite: 21]

## The Solution
[cite_start]I developed an interactive Power BI dashboard to transform messy data into a single source of truth. [cite: 23]
* [cite_start]**Data Transformation:** Used Power Query to clean and structure 3,000+ records. [cite: 24, 29]
* [cite_start]**Interactive Analysis:** Implemented dynamic slicers and DAX measures (like "Final Count") to ensure accuracy. [cite: 25, 33]
* [cite_start]**Strategic Visualization:** Used Treemaps and Trend Lines to make global threat levels understandable in seconds. [cite: 26, 45]

## Key Insights
* [cite_start]**Top Attack Vectors:** **DDoS** (531) and **Phishing** (529) are the most frequent threats. [cite: 50, 98]
* [cite_start]**Most Targeted Region:** The **UK** is the most attacked country (321), followed by Brazil and India. [cite: 71, 100]
* [cite_start]**Industry Trends:** The **IT industry** is the most attacked sector, while **Banking** has the lowest resolution time. [cite: 87, 91]
* [cite_start]**Defense Vulnerabilities:** **Antivirus systems** face the highest number of attacks among defense mechanisms. [cite: 63, 101]
* [cite_start]**Attack Sources:** Analysis shows a balanced contribution from Nation-states, Insiders, and Hacker Groups. [cite: 102]

## Tools Used
