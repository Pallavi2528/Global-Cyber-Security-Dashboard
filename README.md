# Global Cyber Security Threats Analysis (2015-2024)

## Project Overview
This project provides a deep-dive analysis into how cyber-attacks have evolved over a 10-year period (2015–2024). By examining a comprehensive dataset of over **3,000 recorded incidents**, the study identifies who is behind the attacks, the methods used, and which countries are hit the hardest.

* **Timeline:** 2015 – 2024
* **Data Volume:** 3,000+ attack records
* **Interactive Element:** Power BI dashboard for exploring threat data

## Problem Statement
In the modern digital landscape, cybersecurity data is often massive and unorganized, making manual identification of trends nearly impossible.
* **Invisible Trends:** It was unclear if global attacks were increasing or decreasing over the decade.
* **Target Blindness:** There was no easy way to see which specific countries or industries were facing the most threats.
* **Defense Gaps:** It was difficult to measure how effectively different industries were resolving incidents.

## The Solution
I developed an interactive Power BI dashboard to transform messy data into a single source of truth.
* **Data Transformation:** Used Power Query to clean and structure 3,000+ records.
* **Interactive Analysis:** Implemented dynamic slicers and DAX measures to ensure accuracy.
* **Strategic Visualization:** Used Treemaps and Trend Lines to make global threat levels understandable in seconds.

## Key Insights
* **Top Attack Vectors:** **DDoS** (531) and **Phishing** (529) are the most frequent threats.
* **Most Targeted Region:** The **UK** is the most attacked country (321), followed by Brazil and India.
* **Industry Trends:** The **IT industry** is the most attacked sector, while **Banking** has the lowest resolution time.
* **Defense Vulnerabilities:** **Antivirus systems** face the highest number of attacks among defense mechanisms.
* **Attack Sources:** Analysis shows a balanced contribution from Nation-states, Insiders, and Hacker Groups.

## Tools Used
* **Microsoft Excel:** Data preparation, cleaning, and standardizing.
* **Microsoft Power BI:** Dashboard building and interactive data modeling.
* **DAX (Data Analysis Expressions):** Custom measures for accurate real-time filtering.
